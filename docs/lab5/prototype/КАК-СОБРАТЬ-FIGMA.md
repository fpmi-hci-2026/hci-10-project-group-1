## Шаг 1. Снять скриншоты (30 минут)

В Firefox: **Ctrl+Shift+M** — режим адаптивного дизайна. Сверху появится поле ширины.
Вводите нужное число, затем кнопка с фотоаппаратом справа — «Сделать скриншот».
Если её не видно: ⋮ в панели → «Take a screenshot».

> Важно: снимать **всю страницу целиком**, а не видимую часть.
> В обычном окне: правой кнопкой по странице → «Сделать скриншот» → «Сохранить всю страницу».

## Шаг 2. Создать файл и переменные (40 минут)

1. figma.com → **New design file**. Назвать `МаркетШоп.by — ЛР5`.
2. Слева внизу панель слоёв → вкладка **Local variables** (иконка 🎚 на правой панели,
   если файл пустой — Design → Local variables).
3. **Create collection** → имя `color`.
4. Добавить режимы: кнопка **+** рядом с названием режима → создать
   `C-light` и `C-dark`.
5. Внести значения из `design/tokens.json` → `palettes.c`. Имена переменных
   должны совпадать с ключами: `bg`, `surface`, `text`, `brand`, `accent`, `on-accent`
   и так далее — 31 штука.

> Если 31 значение вручную утомительно — внесите хотя бы 10 основных
> (`bg`, `surface`, `surface-alt`, `text`, `text-muted`, `border`, `brand`,
> `on-brand`, `accent`, `on-accent`). Этого достаточно, чтобы показать работу
> с переменными и переключение тёмной темы.

## Шаг 4. Разложить скриншоты по фреймам (30 минут)

На странице `01 Адаптив — веб`:

1. Клавиша **F** → нарисовать фрейм. Справа задать точную ширину: 1440.
2. Перетащить `cat-1440.png` внутрь фрейма, растянуть по ширине.
3. Переименовать фрейм: `Каталог — 1440`.
4. Повторить для остальных пяти ширин.
5. Над каждым фреймом подписать текстом диапазон: `1440+`, `992–1199` и так далее.
6. Рядом вставить таблицу изменений из `mockups/BREAKPOINTS.md`
   (скопировать текстом — достаточно).

На странице `02 Устройства` — то же для пяти устройств.
Figma умеет сразу: **F** → справа в списке выбрать iPhone SE, iPad mini и прочие.

## Шаг 5. Собрать кликабельный прототип (60 минут)

Самая важная часть: именно она делает прототип интерактивным.

На странице `03 Прототип` разложить фреймы:

| Фрейм | Источник | Размер |
|---|---|---|
| `01 Вход` | нарисовать самим, см. ниже | 375 × 812 |
| `02 Главная` | `proto-feed.png` | 375 × высота скриншота |
| `03 Карточка товара` | `proto-card.png` | 375 × … |
| `04 Ассистент по размеру` | дубль карточки + панель | 375 × … |
| `05 Корзина` | нарисовать самим | 375 × 812 |
| `06 Каталог — веб` | `cat-1440.png` | 1440 × … |

Экран входа рисуется за 10 минут: заголовок, два поля, кнопка «Войти»,
ссылка «Зарегистрироваться». Цвета — из переменных.

### Как навесить переход

1. Клавиша **R** → нарисовать прямоугольник поверх кнопки на скриншоте.
2. В панели справа **Fill** → убрать заливку (или поставить прозрачность 0 %).
3. Выделить прямоугольник → вкладка **Prototype** справа вверху.
4. Потянуть синий кружок с края прямоугольника на нужный фрейм.
5. Настроить: `On click` → `Navigate to` → `Smart animate` или `Instant`.

### Карта переходов — минимум для сдачи

| Откуда | Что нажать | Куда |
|---|---|---|
| `01 Вход` | кнопка «Войти» | `02 Главная` |
| `02 Главная` | любая карточка товара | `03 Карточка товара` |
| `03 Карточка` | блок «Ассистент по размеру» | `04 Ассистент` (как **Overlay**) |
| `04 Ассистент` | «Подобрать размер» | обратно на `03` |
| `03 Карточка` | кнопка «В корзину» | `05 Корзина` |
| `02 Главная` | пункт «Поиск» в нижней панели | `06 Каталог` |
| `06 Каталог` | логотип | `02 Главная` |

Для «Ассистента» на шаге 4 выбрать `Open overlay` вместо `Navigate to` —
это демонстрирует временный интерфейс из ЛР № 2, п. 1.3.

## Шаг 6. Страница компонентов (20 минут)

На `04 Компоненты` нарисовать нативно, не скриншотами:

1. **Кнопка**: прямоугольник + текст → **Ctrl+Alt+K** (создать компонент).
   Продублировать, поменять цвет → выделить оба → **Combine as variants**.
   Свойство назвать `state`, значения `default` и `hover`.
2. **Бейдж статуса**: шесть штук с подписями из `style-guide/web.md` —
   «Не хватает атрибутов», «Черновик», «На модерации», «Заблокировано»,
   «Возвращено на правку», «Опубликовано».
3. **Уровень уверенности**: три бейджа — низкая, средняя, высокая.

Этого достаточно, чтобы показать владение компонентами и вариантами.

## Шаг 7. Ссылка (2 минуты)

1. Правый верхний угол → **Share**.
2. Переключить `Anyone with the link` → `can view`.
3. Нажать **Copy link**.
4. Проверить ссылку **в приватном окне браузера** — частая ошибка, когда
   ссылка открывается только у автора.
5. Для режима прототипа: кнопка **▶ Present** → скопировать адрес оттуда.

Прислать обе ссылки — на файл и на прототип.

## Если времени совсем нет

Минимум, который закрывает требование методички «разработайте интерактивный
прототип, иллюстрирующий авторизацию, работу с элементами каталога,
добавление товара в корзину»:

**Шаги 0, 1, 4, 5, 7** — четыре фрейма (`Вход`, `Главная`, `Карточка`, `Корзина`)
и четыре перехода между ними. Примерно час.

Переменные и компоненты добавляются потом, они улучшают оценку,
но не являются обязательным выходным документом.
