# Руководство по стилям — веб-приложение МаркетШоп.by

Сформировано `tools/gen_style_guide.py` из `design/tokens.json`. Правка значений выполняется в токенах, а не в этом файле.

## 1. Логотип

Текстовый логотип **МаркетШоп.by**, гарнитура Manrope ExtraBold. Часть «.by» набирается акцентным цветом — она отсылает к национальному домену и к позиционированию площадки для белорусских брендов.

| Правило | Значение |
|---|---|
| Охранное поле | не менее высоты строчной буквы «о» со всех сторон |
| Минимальный размер | 120 px по ширине (веб), 96 px (мобильный) |
| Монохром | на цветной подложке — целиком цветом `on-brand` |
| Поведение | клик ведёт на главную (зафиксировано в ЛР№2, п. 2.3) |

Запрещено: менять пропорции, добавлять тень и обводку, набирать другой гарнитурой, размещать на пёстрой фотографии без подложки.

### Проверка контраста

Все пары «текст — фон» проверены по WCAG 2.1 скриптом `tools/check_contrast.py`: 126 пар, из них 120 обязательных, ни одна не ниже порога. Полный отчёт — `design/contrast-report.md`.

> При проверке выяснилось, что акцентный `#E07A3F` из ЛР№2 даёт с белым текстом контраст 2,99:1 и не проходит уровень AA. Для заливки кнопок введён затемнённый тон, а исходный оттенок сохранён как `decor` — для бейджей и плашек, где поверх него нет белого текста.

## 6. Обработка ошибок

API возвращает ошибки в формате `application/problem+json` (RFC 9457). Поле `title` выводится заголовком баннера, `detail` — подписью, массив `missing` подсвечивает конкретные поля формы.

| Код | Операций в API | Заголовок | Как показывать |
|---|---|---|---|
| 401 | 47 | Требуется вход в систему | модальное окно входа поверх текущего экрана; после входа возврат к прерванному действию |
| 404 | 24 | Не найдено | экран «Не найдено». Чужой ресурс отдаёт 404, а не 403 — интерфейс не должен намекать, что объект существует |
| 400 | 16 | Ошибка в запросе | подсветка поля формы и подпись под ним |
| 409 | 15 | Конфликт состояния | баннер с текстом из поля detail, например «Описание заблокировано до правки: найдена формулировка „лучший“» |
| 403 | 14 | Недостаточно прав | баннер в теле страницы, не модальное окно — пользователь не может это исправить |
| 422 | 12 | Нарушено правило | подсветка конкретных полей из массива missing; общий баннер сверху |
| 429 | 3 | Слишком часто | тост с обратным отсчётом до повторной попытки |
| 413 | 2 | Превышен размер | ошибка у поля загрузки: партия не более 20 позиций, файл не более 10 МБ |
| 503 | 1 | Сервис генерации недоступен | отдельное состояние кнопки «Сгенерировать описание»: кнопка неактивна, рядом подпись и кнопка «Повторить» |

Код 401 встречается в 47 операциях из 55 — это самое частое состояние системы, и проектировать его следует первым.

## 7. Тон голоса

| Ситуация | Текст |
|---|---|
| Возврат: заказ не получен | Заказ ещё не получен (статус: …). Возврат оформляется после вручения; до передачи в доставку заказ можно отменить. |
| Возврат: невозвратная категория | Товары категории «…» надлежащего качества не подлежат возврату по законодательству. При браке оформите заявку с причиной «брак». |
| Возврат: истёк срок | Срок возврата истёк 12.10.2026 (14 дней с момента получения). При браке обратитесь к продавцу. |
| Возврат: заявка уже есть | По этой позиции заявка на возврат уже оформлена. |
| Описание: подблок не заполнен | Продавец не указал |
| Генерация: неполные атрибуты | Не хватает атрибутов: Размерная сетка. Заполните их, чтобы сформировать описание. |

**Запрещённые формулировки** в описаниях товаров: «лучший», «100% не сядет», «не вызывает аллергии» и прочие непроверяемые заявления о качестве. Проверка выполняется на сервере и не может быть обойдена правкой текста.

**Запрещённые термины** в покупательском контуре: NLP, LLM, «ИИ-описание», «нейросеть», «сгенерировано автоматически». Польза формулируется простым языком.

### Что в каком контуре показывается

| Элемент | Покупатель | Продавец | Модератор | Администратор |
|---|---|---|---|---|
| Полное описание товара | ✅ | ✅ | ✅ | ✅ |
| Индикатор уверенности генератора | ❌ | ✅ | ✅ | ✅ |
| Утверждение ↔ атрибут-источник | ❌ | ✅ | ✅ | ✅ |
| Найденная запрещённая формулировка | ❌ | ✅ | ✅ | ✅ |
| Версия шаблона промпта | ❌ | ✅ (аналитика) | ❌ | ✅ |
| Термины NLP, LLM, «ИИ-описание» | ❌ | ❌ | ❌ | ❌ |

Ограничение проведено не только в текстах: в схемах покупательского API полей `confidence` и `claims` нет вовсе.

## 8. Фотографии товара

| Правило | Значение |
|---|---|
| Соотношение | 3:4, вертикальная ориентация |
| Фон | нейтральный светлый или белый |
| Обязательные кадры | общий план на модели; фактура ткани крупно; деталь; предметный кадр |
| Галерея карточки | не менее 4 кадров, первый — общий план |

Кадр с фактурой ткани иллюстрирует подблок «Состав», предметный кадр — «Посадку». Это не украшение: фотография должна подтверждать то, что написано в описании.

## 12. Что делать и чего не делать

| Правильно | Неправильно |
|---|---|
| Описание размещено выше кнопки «В корзину» (AC-02.1) | Описание спрятано под вкладку ниже кнопки |
| Незаполненный подблок заменён строкой «Продавец не указал» | Подблок отсутствует или пуст |
| Ошибка 422 подсвечивает конкретные поля | Общий текст «проверьте данные» |
| Бейдж статуса берёт цвет из токена | Цвет задан числом в вёрстке |
| Кнопка в состоянии loading блокирует повторное нажатие | Повторные нажатия создают дубль заявки |
