## Project Name

**МаркетШоп.by** — маркетплейс одежды и обуви для Республики Беларусь с модулем
автоматической генерации и персонализации описаний товаров.

## Description

Проектируемая система — веб- и мобильное приложение маркетплейса, ключевой особенностью
которого является автоматическое формирование достоверных описаний товаров из
структурированных атрибутов (материал, крой, размерная сетка бренда, сезон, уход) и их
персонализация в рекомендательных блоках. Продукт решает две задачи, подтверждённые опросом
46 респондентов: снижает неопределённость при выборе товара (60,9% сталкивались с
несоответствием описания реальности) и сокращает долю возвратов, оформление которых названо
барьером №1 для 39,1% опрошенных. Помимо витрины покупателя система включает кабинет
продавца с генерацией и редактированием описаний и панель администратора с очередью
модерации и настройкой правил генерации. Отдельный контур обеспечивает достоверность: каждое
утверждение описания возводится к атрибуту-источнику, а неподтверждённые заявления о качестве
блокируются до публикации.

## Installation

Репозиторий содержит документацию и отчёты; приложения — в репозиториях, подключённых как подмодули
(см. [Sub modules](#sub-modules)). Для запуска нужны Docker с Compose v2 и 6 ГБ памяти для контейнеров.

```bash
# клонировать вместе с репозиториями приложений
git clone --recurse-submodules https://github.com/fpmi-hci-2026/hci-10-project-group-1.git
cd hci-10-project-group-1

# серверная часть: сервисы, шлюз и инфраструктура
cd backend && cp .env.example .env && docker compose up --build

# веб-приложение (в другом терминале, нужен Node.js 20)
cd frontend && npm ci && npm run dev
```

Мобильное приложение собирается в Android Studio или командой `./gradlew assembleDebug` в каталоге `mobile/`.
Подробности — в README каждого подмодуля.

## Usage

Развёрнутое приложение: веб — https://marketshop-five.vercel.app, API и Swagger UI — https://marketshop-gateway.onrender.com/swagger-ui.html
(бесплатные сервисы Render засыпают без запросов, первый ответ — около минуты).

Локальный запуск:

| Что | Адрес |
|-----|-------|
| Веб-приложение | http://localhost:5173 |
| API и Swagger UI | http://localhost:8080/api/v1 · http://localhost:8080/swagger-ui.html |

Демонстрационные пользователи (пароль `marketshop`): покупатель `anastasiya@example.by`, продавец `viktor@denim.by`,
администратор `marina@marketshop.by`.
