## Project Name

**МаркетШоп.by** — маркетплейс одежды и обуви для Республики Беларусь с модулем
автоматической генерации и персонализации описаний товаров.

## Description

Проектируемая система — веб- и мобильное приложение маркетплейса, ключевой особенностью
которого является автоматическое формирование достоверных описаний товаров из
структурированных атрибутов (материал, крой, размерная сетка бренда, сезон, уход) и их
персонализация в рекомендательных блоках. Продукт решает две задачи, подтверждённые опросом
46 респондентов: снижает неопределённость при выборе товара (60,9% сталкивались с
несоответствием описания реальности) и сокращает долю возвратов, оформление которых названо
барьером №1 для 39,1% опрошенных. Помимо витрины покупателя система включает кабинет
продавца с генерацией и редактированием описаний и панель администратора с очередью
модерации и настройкой правил генерации. Отдельный контур обеспечивает достоверность: каждое
утверждение описания возводится к атрибуту-источнику, а неподтверждённые заявления о качестве
блокируются до публикации.
